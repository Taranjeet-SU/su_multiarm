# Review of addendum A2 rev 1 (log analytics, accounted coverage, UI, MCP), round 1

Reviewed: `docs/plans/v2_addendum_log_analytics_ui.md` (untracked, worktree on `v2/logs` at `106d4b0`), against the
code at `106d4b0`, A1 rev 3 (`docs/plans/v2_addendum_logs_and_patterns.md`), the execution log, the main plan and
`AGENTS.md`. Deployment-specific observations are kept in a private review outside this repository. Line numbers
like `A2:434` refer to the addendum; code paths are relative to `src/su_multi_arm/`.

**VERDICT: REVISE**

The direction is right. Treating "100 % coverage" as "every line accounted for, with deterministic coverage as the
headline" is a faithful and testable reading, provided the owner accepts it explicitly. Cluster-first fallback with
values taken only from regex spans or located quotes is the right grounding design. The cost arithmetic checks out
at the illustrative price. A static SPA served on the package's own origin is the right stack. Read-only by
default, with a copy-the-CLI-command flow, is the right promotion default. Ten problems block a correct build,
though:

- The headline accounting identity is not defined on the unit the code actually counts.
- The fallback has no defined place in the daily pipeline, which today seals partitions as immutable before any
  learning.
- Every library change reparses and recomposes the whole window, so delta compose does not fix the daily path the
  owner configured.
- The tenant ACL promised for the UI, inspect routes and MCP cannot hold with the planned document kinds and the
  built-in principals.
- The "one plan path for decision agent, UI and MCP" claim has no contract behind it for the `llm` and `cascade`
  agents.
- Typed field values, which `endpoint_day` and `exception_day` need, are not stored in partitions, and no
  partition format version is planned.
- The model-assisted graph rule contradicts a validator in the code.
- Serving-path generation pins are claimed but not wired and not scheduled.
- Two measured defects that break the serving path and community determinism are left out of P0.
- An unauthenticated loopback UI is offered without DNS-rebinding protection.

All are fixable in the plan without changing its shape.
